# 基于 SpringBoot + Vue 的英语单词学习进度系统 (English Vocabulary Learning System)

单词背诵 · 在线答题 · 阅读拓展 · 社区互助 · AI 答疑 · 教学管理

本项目是一套面向英语学习场景的单词学习与进度管理系统，采用前后端分离架构，覆盖管理员、教师、学生三类角色。平台围绕“单词记忆、在线答题、错题回顾、英语阅读、社区问答、AI 智能答疑、学习足迹追踪、教学管理”等核心业务设计，支持学生自主背词、在线测试、错题收藏、笔记沉淀、社区互助学习，教师发布通知、答疑辅导、引导学习社区，管理员进行题库维护、内容监管、用户管理与多维度数据统计分析，适用于高校英语课程、语言培训机构、在线背词平台及校园英语学习社区。

## 核心特性

- **单词学习与答题训练闭环**：支持单词背诵、释义查看、发音学习、在线答题、错题回顾与题目收藏，形成完整学习路径。
- **阅读与语境学习**：提供英语文章阅读资源，关联生词解析，帮助用户在语境中掌握单词用法。
- **社区互助与师生互动**：内置问答社区、帖子讨论、私信沟通与关注机制，支持学生互助、教师答疑与优质内容沉淀。
- **AI 智能答疑**：集成 AI 助手，自动回复用户学习问题，并保留答疑记录供复习与优化知识库。
- **学习进度与行为追踪**：记录用户答题历史、学习足迹、笔记、收藏、投票与活跃时段，构建个人学习档案。
- **教师教学支持**：教师可发布公告、解答问题、参与社区讨论、收藏教学资源，辅助班级教学管理。
- **多维度数据看板**：提供注册用户、日活、留存、活跃度、高频词云、用户画像等统计分析，辅助平台运营与教学优化。

## 功能模块概览

### 管理员端

管理员端负责平台整体运营、内容监管、题库维护与数据分析：

**内容资源管理**

- **单词管理**：录入、编辑和维护单词库，包括释义、音标、例句、发音与关联知识点。
- **英文文章**：发布和管理英语阅读材料，支持关联生词解析与难度分级。
- **题库信息**：管理试题类型、难度分级、知识点标签及题目上下架状态。
- **公告信息**：发布系统通知、考试安排、活动公告及学习资讯。

**社区与互动监管**

- **收藏贴子**：监控全站热门收藏内容，筛选并管理优质社区资源。
- **顶踩投票**：管理社区内容的点赞与点踩数据，维护内容质量与排序规则。
- **用户关注**：查看用户关注关系链，分析社群影响力与学习圈层。
- **交流模块**：设置社区板块分类、访问权限、显示状态与内容规则。
- **交流回复**：查看并处理用户在社区的评论与互动内容。
- **问题回答 / 问题答疑**：从后台视角处理用户反馈的系统性问题，监控问答板块未解决的疑难内容。
- **交流沟通**：监控系统内私信流转，拦截违规通信，保障社区安全。

**用户与教学管理**

- **用户管理**：管理学生账号信息，处理封号、状态变更与权限调整。
- **教师管理**：管理教师账号、权限分配、教学科目及资质审核。
- **用户笔记**：审核用户发布的公开笔记，处理违规或低质内容。
- **题目收藏**：查看高频收藏题目，分析试题热度与学习难点。
- **学习足迹**：查看用户学习路径、打卡记录与活跃时间段。
- **AI 答疑记录**：查看 AI 自动回复历史，优化问答知识库与回复策略。

**数据统计与运营分析**

- **数据统计**：生成注册用户数、日活、留存、答题量等基础运营报表。
- **活跃度指标**：分析用户发帖量、答题量、收藏量等核心活跃度指标。
- **时间分布**：分析用户学习高峰时段，优化服务器资源与内容推送策略。
- **用户画像**：基于学习数据构建用户能力模型、兴趣标签与学习阶段画像。
- **高频词云**：可视化展示用户查询、出错或收藏的高频词汇，辅助教学重点调整。
- **答题记录**：查看全站用户答题历史、成绩分布及错题集中情况，支持考试监管。
- **消息通知**：向特定群体或全员发送系统推送消息、学习提醒与活动通知。

### 教师端

教师端作为教学工作台，支持通知发布、答疑辅导与社区引导：

**个人中心与通知**

- **个人中心**：聚合教学任务、待答疑问题、学生互动数据等工作台信息。
- **公告信息**：查看平台公告，或发布班级通知、作业布置与学习安排。
- **消息通知**：接收学生提问提醒、系统任务通知与教学相关推送。
- **教师信息**：维护个人简介、教学科目、联系方式与教学风格说明。

**答疑与互动**

- **问题答疑**：查看待解决问题列表，针对学生提问提供专业解答。
- **我的回复**：查看自己给出的所有解答、评论与互动历史。
- **在线沟通**：与学生进行一对一私信交流，解答个性化学习问题。
- **社区交流**：参与社区讨论，引导正确学习氛围，推荐优质学习资源。
- **交流内容**：监控并参与特定板块的讨论，关注共性问题与学习动态。

**资源收藏**

- **贴子收藏**：收藏优秀教学案例、学生共性问题或高质量学习分享，便于后续教学复用。

### 学生端

学生端以小程序或 H5 为主要入口，提供单词学习、答题训练、阅读拓展与社区互动体验：

**核心学习功能**

- **单词学习**：进行单词背诵、复习，查看详细释义、音标、例句与发音。
- **在线答题**：参与单词拼写、选择题等测试，即时查看分数与解析。
- **答题记录**：查看过往考试成绩、错题集、练习历史与掌握情况。
- **英语文章**：阅读精选英语文章，在语境中学习单词用法与表达方式。
- **学习教育**：访问系统提供的课程、教程、学习资料包与学习路径推荐。

**社区与互动**

- **社区问答**：浏览问答区，查找语法、词义或学习方法相关解答。
- **社区交流**：进入讨论区，分享学习经验、打卡记录或参与话题讨论。
- **问题发布**：发布学习中遇到的难题，请求同学或老师解答。
- **我的发帖**：管理自己发布的经验分享、讨论帖与学习内容。
- **我的回复**：查看自己在社区内的所有评论与回复历史。
- **贴子收藏**：收藏有价值的学习攻略、经验分享帖或优质回答。
- **我的投票**：查看自己对帖子或回答进行的点赞 / 点踩记录。
- **我的关注**：关注学霸或老师，获取其动态更新与学习分享。
- **在线沟通**：与同学或老师进行一对一私信交流，讨论学习问题。

**个人学习与设置**

- **个人中心**：聚合个人学习数据、收藏内容、学习进度与系统设置的总览页。
- **个人信息**：修改头像、昵称、学习目标与学习偏好设置。
- **我的笔记**：记录和管理个人单词笔记、语法总结与学习心得。
- **收藏题目**：收藏典型错题或高难度题目，便于反复练习与复习。
- **学习足迹**：回顾学习日历、每日打卡记录与单词学习进度。
- **AI 答疑记录**：查看与 AI 助手的对话历史，复习知识点与疑难解答。
- **消息通知**：接收作业提醒、回复通知、系统公告与学习进度提醒。
- **公告信息**：查看考试安排、系统通知、活动公告及学习建议。
